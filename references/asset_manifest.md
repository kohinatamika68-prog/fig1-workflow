# Bundled visual and source assets

The assets are reference material and an editable exemplar. Use them to understand
composition and visual treatment; do not copy their unrelated data or claims.

| Asset | Role |
| --- | --- |
| `reference_cool_figures_grid.png` | User-provided moodboard showing the desired rich scientific-figure feel. |
| `reference_flowchart_revision.vsdx` | First Visio layout reference. |
| `reference_flowchart_method.vsdx` | Second Visio layout reference. |
| `fig1_editable_exemplar.vsdx` | Current FAR Fig. 1 native editable source. |
| `fig1_overview_with_panels.png` | Current overview render, including the three compact scientific panels. |
| `fig1_overview_with_panels.svg` | Vector overview export for inspection. |
| `fig1_overview_with_panels.pdf` | Vector overview export used as a paper-figure reference. |
| `profile_correlation.png`, `regime_radar.png`, `speedup_raincloud.png` | Individual compact panels used inside the overview. |
| `workload_regimes.png` | Expanded workload-regime radar. |
| `workload_regimes.pdf` | Vector export of the expanded workload-regime radar. |
| `speedup_distributions.png` | Expanded raincloud comparison. |
| `speedup_distributions.pdf` | Vector export of the expanded raincloud comparison. |
| `runtime_structure.png` | Expanded correlation and per-dataset structure figure. |
| `runtime_structure.pdf` | Vector export of the expanded runtime-structure figure. |
| `source_templates/` | Adaptable FAR generator and verifier sources used to produce the exemplar. |

The two reference VSDX files are style inputs only. The current editable exemplar and
the expanded chart exports are the primary examples for future adaptation.
